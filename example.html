[Ví dụ] Vùng chứa có 5 div & Áp dụng flex-grow lên Div 2

Mô tả: Trong vùng chứa flexbox này có 5 thẻ div. Cả 4 div (1, 3, 4, 5) có kích thước cố định ban đầu là 100px và flex-grow: 0. Riêng Div thứ 2 được thiết lập flex-grow: 1, cho phép nó tự động hấp thụ toàn bộ khoảng trống còn lại trong vùng chứa để nở rộng ra so với các div khác.
Div 1 grow: 0
Div 2 (Tăng trưởng) grow: 1 (Phát triển)
Div 3 grow: 0
Div 4 grow: 0
Div 5 grow: 0
Mã nguồn CSS tương ứng:
/* Container có thuộc tính display: flex */
.container {
  display: flex;
  gap: 12px;
}

/* 5 item đều có chiều rộng khởi điểm là 100px và flex-grow mặc định là 0 */
.box {
  width: 100px;
  flex-grow: 0;
}

/* Chỉ riêng Div 2 áp dụng flex-grow: 1 */
.box-2 {
  flex-grow: 1; /* Div 2 sẽ phát triển và chiếm trọn không gian thừa */
}
